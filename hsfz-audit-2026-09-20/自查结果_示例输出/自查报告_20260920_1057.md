## 五、整改建议（按优先级）

1. **数据归属校验**：查询类接口默认以会话持有者为过滤条件；仅当具备
   相应角色（班主任/宿管/德育/管理员）时才允许查询他人数据。
2. **网关层按 CODE 建立角色白名单**：学生角色默认拒绝管理类 CODE。
3. **`pageSize` 服务端强制上限**（建议 ≤ 200）。
4. **修复 JWT 未被校验的问题**（见第二节对照）。
5. **排查导出接口 `respUrl`** 是否需要鉴权、是否已生成可下载明文包。
6. 启用接口调用审计日志，对单次返回大量个人信息记录的调用告警。
