### 【NEW-1】`hfwps.TARGET.example.edu:5555` 反射型 XSS（已实弹验证）★★★★ 本轮最高成色

- **类型**：跨站脚本（CWE-79 反射型）
- **位置**：`http://hfwps.TARGET.example.edu:5555/soft?search=` （同样存在于 `/help`、`/soft/search`，共 3 处）
- **成因**：`search` 参数回显进 `<input value="…">` 属性，**双引号与尖括号均未做 HTML 实体编码**，可闭合属性与标签逃逸。
- **验证载荷**：
  ```
  GET http://hfwps.TARGET.example.edu:5555/soft/search?search=x%22%3E%3Cscript%3Ealert(USER_43cc23.domain)%3C%2Fscript%3E
  ```
- **服务端原始输出（未编码，铁证）**：
  ```html
  <input type="text" name="search" USER_409788="请输入软件名称" value="x">
  <script>alert(USER_43cc23.domain)</script>
  ```
- **真实浏览器实弹结果**（Chromium 无头，监听 dialog 事件）：
  ```
  status: 200
  dialog fired: {"type":"alert","message":"hfwps.TARGET.example.edu"}   ← 脚本已执行
  injectedScriptFound: 1
  injectedText: "alert(USER_43cc23.domain)"
  inputOuterHTML: <input type="text" name="search" ... value="x">
  CSP: none
  ```
  截图证据：`recon/xss_proof.png`
- **防护失效说明**：响应带 `X-XSS-Protection: 1; mode=block`，但现代浏览器已移除该机制，**未生效**；且站点**无 CSP**，脚本执行无任何阻碍。
- **危害**：
  - 域名 `hfwps.TARGET.example.edu` 属于学校自有域名，师生信任度高，可通过校园群/邮件批量投递恶意链接；
  - 无 CSP 意味着注入脚本可完整重写页面内容 —— **伪造登录表单钓鱼**、劫持下载链接（把 `GP(TARGET)-4.0.2.0.exe` 换成木马）均可实现；
  - 该站**仅提供明文 HTTP**，网络位置的中间人无需 XSS 即可注入任意内容，两者叠加。
- **局限性（诚实标注）**：hfwps 自身会话 Cookie 为 `HttpOnly`，且主站 Cookie 为 host-only，**此 XSS 无法直接窃取跨域会话**。危害主要落在钓鱼与内容篡改，因此定为**中危偏高（CVSS 约 6.1）**，不宜夸大为高危。
- **修复**：输出点对 `"` `<` `>` `&` 做 HTML 实体编码（或改用框架的安全绑定）；补充 `Content-Security-Policy`；全站 HTTPS。

### 【NEW-4】情报修正：SSO 登录端点与参数结构（前三轮均打错位置）

前三轮一直重放 `/USER_87780f/logon`，**该端点不是该校实际使用的登录入口**。真实结构由浏览器拦截登录请求获得（请求已被 harness 拦截，**未送达服务器**）：

```
POST /api/USER_429c64/USER_d9833f/auth/USER_4a2dbd
{
  "state": {"organizeCode": null, "roleAlias": null},
  "data": {
    "USER_16f78a":   "<账号>",
    "USER_5e8848":   "<密码>",
    "loginType":  4,          // 1=手机号  4=学籍号/工号
    "orgAlias":   "huafu"     // 必须为 huafu；其他值返回「目标数据不存在」
  }
}
```

关键推论：
- `orgAlias`（登录参数）与 `state.organizeCode`（业务参数）**是两套标识**。`huafu` 是 alias，业务接口的 `organizeCode` 仍是未知值 —— 这解释了第四轮中带 token 请求返回 `400004 非法组织` 的原因。
- 该校定制登录表单 `HFPasswordLoginForm` **不启用图形验证码**（仅 `USER_16f78a`+`USER_5e8848`+协议勾选），通用版才走 `imageCaptchaCode`。
- 提交前置条件：必须勾选协议 USER_6fe9eb，否则前端直接 `error("请阅读相关协议")` 不发起请求。
